# 目次の可読性と現在節表示の改善（2026-11-25）

## 問題
従来は muted 色へ opacity: 0.7 を重ね、文字のコントラストがライト約3.13:1、ダーク約3.81:1だった（元の文字色と目次背景をsRGBで合成して計算）。
本文と似た背景色・薄い枠・12pxの字下げだけでは、目次の役割と階層、読んでいる節を判別しにくかった。

## 設計と実装
- デスクトップ（769px以上）は背景・外枠・内側余白を除去。「目次」のcaptionラベル、リスト全体に2pxのガイド線、現在節だけアクセント色の線を表示。幅220pxとsticky配置は維持。
- 第1階層はfootnote（14px、400）、第2階層以降は専用tocNestedトークン（13px、400）。第2〜4階層の字下げは12／24／36px。opacityは1。
- 現在節はtext色・500・aria-current="location"。例えば「テスト」の見出し上端が画面上端から120pxを通過すると、対応する13pxの項目だけ太字とアクセント線になる。
- IntersectionObserverで本文h2〜h5を監視し、scroll／resizeでも全見出しの実位置から最後に120pxを通過した見出しを選択。最初の見出し前は未選択、ページ最下部は末尾を選択する。記事変更／アンマウント時はobserverとイベントリスナーを解除。
- 既存のRemix Linkのハッシュ遷移を維持。通常クリックのみ選択を即反映し、修飾キー操作はそのまま。履歴や独自のPOP処理は追加していない。
- モバイル（768px以下）はdetails／summaryを維持。背景をライト#FFFFFF、ダーク#14162Bへ変更し、borderColorの1px枠と8px角丸を適用。
- pointer:fineは最小32px、coarseは最小44px。アニメーション／トランジションを追加していないため、prefers-reduced-motionでも動きを追加しない。
- TOC専用のtocMuted／tocBackgroundをテーマ変数へ定義し、ほかのmuted表示へ影響を広げない。データアクセスや外部依存は追加していない。
- 変更対象の既存TableOfContentsはブログ詳細が利用している。現行Works詳細には目次自体がないため、今回の指定ファイル内での再設計にはWorksルートへの新規設置を含めていない。

## before → after
- 従来の全リンク：約3.13:1（ライト）／約3.81:1（ダーク）→ 不透明な文字色。
- デスクトップの第1階層・現在節：18.21:1（ライト#03031B対#F2F1FF）／15.19:1（ダーク#DEDBFF対#03031B）。
- デスクトップの第2階層以降：5.78:1（ライト#5B5D72対#F2F1FF）／7.14:1（ダーク#999999対#03031B）。
- モバイルの第1階層・現在節：20.33:1（ライト#03031B対#FFFFFF）／13.30:1（ダーク#DEDBFF対#14162B）。
- モバイルの第2階層以降：6.45:1（ライト#5B5D72対#FFFFFF）／6.25:1（ダーク#999999対#14162B）。
- 以上はブラウザーのgetComputedStyleで得た文字色と実背景色からWCAG相対輝度式で算出。すべてAAの4.5:1以上。現在節は階層にかかわらずtext色なので、同じ値。
- 階層：字下げのみ → 14／13pxの文字サイズ・色・字下げを併用。現在節：表示なし → 500の文字と2pxのアクセント線。
